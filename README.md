AI SMM Assistant Telegram Bot
Интеллектуальный Telegram-бот для автоматической генерации маркетингового контента, идей для постов и контент-планов с использованием искусственного интеллекта.
 О ПРОЕКТЕ
Этот бот создан для помощи SMM-специалистам, маркетологам и владельцам бизнеса. Он избавляет от рутины при создании контента: генерирует креативные идеи, пишет тексты для постов и помогает структурировать контент-план прямо в Telegram.
Стек технологий
Язык: Node.js
Фреймворк для бота: node-telegram-bot-api
ИИ-интеграция: OpenRouter API (подключение языковых моделей)
Веб-сервер: Express.js (для поддержки активности на хостинге)
Хостинг: Render, Uptimerobot (круглосуточная работа 24/7)
Основные возможности
Генерация идей: Подбор тем для постов по заданной нише
Написание текстов: Создание готовых постов для соцсетей с учётом tone of voice
Автономность: Работа в облаке 24/7 без необходимости держать компьютер включенным
